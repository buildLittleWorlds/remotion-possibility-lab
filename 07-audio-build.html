BUILDPAGE 07 / 17

Build a captioned audio clip

Use one prompt, inspect its preview, then continue. Keep the same project conversation so each step adds to the version you have already checked.

If you have not started a project yet, read the getting-started walkthrough. You can replace the example topic after you understand the small working version.

Use the provided assets

Download signal.wav and captions.json. Ask the assistant to place them in your project’s public/media folder. The caption file records the supplied script at sentence boundaries.

Script: “Signal received. A tiny sound can become a visible story. Keep the words readable, and let the waveform follow the voice.”

The standard Samantha synthetic voice is a sample, not Dr. Plate’s voice.

1 / Play the supplied recording

@Remotion Create SignalAudiogram, 1280 by 720 at 30 fps. Use the signal.wav file I supplied in public/media. Set the composition duration to the actual audio length, rounded up to a frame. Show “Make a sound visible” on a dark background and play the recording only when I press Play. Open the preview and stop before adding captions.

Check: listen to the whole short recording. Is its ending present?

2 / Add the supplied captions

@Remotion Use the captions.json file I supplied. Its startMs and endMs values are milliseconds. Display the active sentence when the composition time is inside that interval. Keep the captions large, centered, and high contrast; leave enough room for the longest sentence. Do not invent new text or treat these timestamps as a transcription model.

Check: pause just before and after each sentence boundary.

3 / Make the actual sound visible

@Remotion Add a waveform sampled from signal.wav using Remotion’s audio visualization tools. Drive its time window from the composition frame and fps. Add a Remotion Player interface with two caption styles: high-contrast card and simple text. Changing style pauses and resets playback. Keep the audio and timestamps identical.

Check: the waveform should respond to sound and quiet, and both styles should show the same words.

Continue to the testing page before replacing the recording.
